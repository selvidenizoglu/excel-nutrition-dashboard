# NutriTrack

An Excel-based nutrition and fitness tracker designed to monitor daily calorie intake, protein consumption, exercise expenditure, and energy balance through an automated dashboard.

## Overview

NutriTrack is a personal data tracking project built entirely in Microsoft Excel. It combines structured data management with dynamic reporting to simplify daily nutrition tracking and provide long-term progress insights.

The workbook automatically aggregates food and exercise records into a dashboard displaying key metrics such as calorie intake, protein intake, calorie deficit, progress, and averages.

---

## Features

- Food logging system
- Exercise logging
- Automated calorie and protein calculations
- Dynamic daily dashboard
- Running calorie deficit tracking
- Daily averages
- Progress monitoring
- Conditional formatting for quick visualization
- PivotTable-based reporting

## Purpose

This project was created to improve Excel data analysis skills while solving a real-world personal tracking problem.

The primary goals were to gain practical experience with structured datasets, lookup functions, PivotTables, dashboard creation, and automated reporting.
